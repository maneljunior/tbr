# Maquete 3D – Ambiente Escolar Tecnológico com Materiais Recicláveis

Maquete 3D da sala da equipe **Astrobóticos** (TBR 2026), feita para a turma avaliar antes da impressão 3D.

- Base de 21 × 8 cm e paredes de 7 cm.
- Gire, dê zoom e mostre ou esconda cada peça.
- Clique numa peça para ver as medidas e o filamento sugerido.
- Baixe o STL (em milímetros) de uma peça ou de tudo o que estiver visível.

Para abrir no computador, rode um servidor local nesta pasta (`python -m http.server 8765`) e acesse `http://localhost:8765`. Abrir o arquivo com dois cliques não funciona, porque o navegador bloqueia a carga da biblioteca 3D.
